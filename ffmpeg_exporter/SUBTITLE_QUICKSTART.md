# 🎵 Quick Reference - Subtitle/Lirik SRT

## ⚡ Cara Cepat

### 1. Persiapkan File
```
📁 Music/
   ├── song1.mp3
   ├── song1.srt  ← Nama HARUS sama!
   ├── song2.mp3
   └── song2.srt
```

### 2. Di Aplikasi
1. **Tab Media** → Pilih audio files
2. **Tab Effects** → Scroll ke "SUBTITLE / LIRIK"
3. ☑ **Centang** "Tampilkan Subtitle/Lirik dari SRT"
4. **Atur styling** (font, warna, posisi)
5. **Preview** (optional)
6. **Export** → Done!

## 🎨 Setting Recommended

### YouTube
- Font Size: **28-32**
- Warna: **White** text + **Black** outline (2px)
- Posisi: **Bottom Center**
- Margin: **60-80px**

### TikTok/Instagram
- Font Size: **32-40**
- Warna: **Yellow** text + **Black** outline (3px)
- Posisi: **Top Center** (hindari UI bawah)
- Margin: **80-100px**

## 📝 Format SRT Cepat

```srt
1
00:00:00,000 --> 00:00:03,500
♪ Lirik baris pertama ♪

2
00:00:03,500 --> 00:00:07,000
♪ Lirik baris kedua ♪
```

**Rules:**
- Timing: `HH:MM:SS,mmm`
- Encoding: **UTF-8**
- Extension: `.srt`

## ✅ Checklist

- [ ] File SRT nama sama dengan audio
- [ ] Encoding UTF-8
- [ ] Timing sudah benar
- [ ] Checkbox subtitle aktif
- [ ] Preview styling OK
- [ ] Export!

## 🆘 Troubleshooting

| Problem | Solution |
|---------|----------|
| Subtitle tidak muncul | Check nama file sama persis |
| Karakter aneh | Save SRT dengan UTF-8 |
| Timing salah | Edit timing di SRT editor |
| Warna tidak pas | Gunakan color picker |
